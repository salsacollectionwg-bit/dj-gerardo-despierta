# DJ Gerardo Despierta — actualizaciones

Canal público de actualizaciones de la app **DJ Gerardo Despierta** (reloj y alarmas que saltan los festivos de Colombia).

- `apk/DJ-Gerardo-Despierta.apk` — última versión para instalar.
- `version.json` — la app lo revisa para avisar que hay versión nueva.
- `festivos.json` — correcciones a los festivos calculados en el teléfono:
  - `add`: `[{"date": "AAAA-MM-DD", "name": "Nombre"}]` agrega un festivo.
  - `remove`: `["AAAA-MM-DD"]` quita una fecha.
  - `disableNames`: `["Virgen del Rosario de Chiquinquirá"]` quita ese festivo en todos los años (por ejemplo, si la Corte Constitucional declara inexequible la norma).

Este repositorio no contiene código ni claves; el código está en un repositorio privado.
